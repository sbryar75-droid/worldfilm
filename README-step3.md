# هەنگاوی ٣: Supabase و پانێلی ئەدمین

1. فۆڵدەرەکانی ئەم zip ـە بخە سەر پڕۆژەکەت (Replace).
2. فۆڵدەری src/data بسڕەوە (ئیتر پێویست نییە، داتا لە داتابەیسە).
3. لە terminal:  npm install @supabase/supabase-js @supabase/ssr
4. .env.local.example کۆپی بکە بە ناوی .env.local و بەهاکان پڕ بکەرەوە.
5. supabase/schema.sql لە Supabase SQL Editor جێبەجێ بکە (YOUR_EMAIL پێشتر بگۆڕە).
6. لە Supabase > Authentication > Users ئەکاونتی ئەدمین دروست بکە.
7. npm run dev  ->  http://localhost:3000/admin
