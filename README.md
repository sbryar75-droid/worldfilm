# World Film

## دەستپێکردن
1. Node.js 18.17 یان نوێتر دابمەزرێنە (nodejs.org)
2. لە VS Code دا فۆڵدەرەکە بکەرەوە، پاشان لە terminal:
   npm install
   npm run dev
3. بچۆ بۆ http://localhost:3000

## ستراکچەر
src/app          پەڕەکان (هەر فۆڵدەرێک = ڕێگایەک)
src/components   پێکهاتەکان: layout/ و movie/
src/data         داتای فیلمەکان (دواتر داتابەیس)
src/lib          ڕێکخستنەکان، ناوی سایت لە config.js

## ناوی سایت
src/lib/config.js  ->  SITE_NAME
